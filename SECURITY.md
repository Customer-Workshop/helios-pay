# Security notice

> ⚠️ **Helios Pay is intentionally vulnerable and exists only for security
> demonstrations. Do not deploy it. Do not connect it to real systems or load
> real customer, payment, or credential data.**

Run this project only on an isolated local or workshop network. Never expose
the compose services to the public internet.

The weaknesses in this repository are deliberate demo content and are not
supported production software. **Do not report the intentional demo findings
to us as security vulnerabilities.** Please do report accidental issues that
could affect the workshop infrastructure through the workshop organizers.
